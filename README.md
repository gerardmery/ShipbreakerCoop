# ShipbreakerCoop

Co-op multiplayer mod for Hardspace: Shipbreaker, built with the coop-anything playbook
(https://github.com/cranebeaker/coop-anything).

## Folders
| Folder | What goes here | Commit to git? |
|---|---|---|
| docs/ | Triage brief, design notes, sync list, findings | Yes |
| reference/ripped_project/ | AssetRipper Unity project export | NO, game files |
| reference/notes/ | Your notes and screenshots from browsing the rip | Yes (text only) |
| decomp/ | dnSpyEx decompile of Assembly-CSharp etc. | NO, game code |
| mod/ | BepInEx 5 plugin source (the actual co-op mod) | Yes |
| tests/ | Bot scenarios, sync tests, QA logs | Yes |
| tools/ | Helper scripts, coop-anything tool configs | Yes |

Start with docs/TRIAGE_BRIEF.md.
